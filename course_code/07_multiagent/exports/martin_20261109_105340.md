Hi Martin! To become a data engineer while learning Python:

1. Master Python for data (not web dev): data structures, file I/O, APIs, error handling, logging, virtual environments.
2. Learn SQL deeply—joins, CTEs, window functions, indexing, query optimization (this is often more important than Python for DE roles).
3. Add data tools: Pandas for manipulation, PySpark for big data, dbt for transformations, and Airflow/Prefect for orchestration.
4. Pick one cloud platform (AWS, GCP, or Azure) and learn its core data services (storage, warehouse, compute).
5. Build 3 portfolio projects on GitHub: an API-to-database pipeline, a dbt modeling project, and a cloud-based ETL pipeline.
6. Use Git, document your work with READMEs, and quantify results on your resume.

Start this week: write a Python script that pulls data from a public API and saves it to a CSV or SQLite database, then push it to GitHub.
